# 收盘扫描术语表

页码按 2018 年版 PDF 页序计算，封面为第 1 页。

| 术语 | Pezim 的用法 | 写入观察清单时的区别 | 来源 |
|---|---|---|---|
| 收盘时段 / 收盘价（the close / closing price） | 前者在书中可指常规交易最后一小时；后者是该交易日最终价格。 | 注明观察时刻，避免用收盘价确认后再假设以该价成交。 | 第12章，页112–114；术语表 |
| 市场内部指标 / 市场宽度（market internals） | 从上涨/下跌家数、新高/新低家数、均线上下个股占比等观察参与面。 | 指数涨幅与参与面分开记录；说明比较的股票范围。 | 第12章，页103–104 |
| 板块轮动（rotation） | 资金偏好在行业间变化，作者比较多个时段的行业表现。 | 周强月弱标成分歧，以相同时窗比较。 | 第12章，页104–106 |
| 扫描器 / 观察清单（scanner / watchlist） | 扫描器按条件缩小股票池，观察清单保留有待满足某些条件的标的。 | 为每行填下一次观察什么；JNCE 的阻力仍待突破。 | 第12章，页106–111；术语表 |
| 成交量 / 相对量能（volume / relative volume） | 成交量按股数计；相对量能表示该股成交量与其正常成交量的倍数。 | 保留平均量的回看期与数据商口径；放量本身不区分买卖方向。 | 第12章，页107–110；术语表 |
| 流通股 / 空头占流通股比例（float / float short） | 流通股是可交易股数；空头股数相对于流通股的比例表示潜在回补规模。 | 股数、比例、当天卖空成交量为不同字段；高空头占比还需触发条件才可能轧空。 | 第6章，页46–47；第12章，页109–114 |
| 均线 / 动量指标（SMA / RSI / MACD） | SMA 汇总收盘价；RSI 比较近期涨跌强度；MACD 观察快慢均线差及其与信号线的关系。 | 注明周期。RSI 是单标的动量，板块相对强弱另算；作者第8章的极值偏好和表12.1的筛选取值可不同。 | 第8章，页72–79；第12章，页109–110 |
| 平均真实波幅（ATR） | 把当日高低差以及高低价到前收盘的距离纳入真实波幅，再在一定期间平滑。 | ATR 单位与报价相同，可检视止损是否落在日常噪声里，无法预测涨跌方向。 | 第8章，页79–82 |
| 支撑 / 阻力（support / resistance） | 价格曾多次暂停或反向的区域，可用于定位假设失效或潜在获利位置。 | 区分实际测试与预想的突破；旧价位在被越过后可能改变角色。 | 第8章，页69–72 |
| 催化事件（fundamental catalyst） | 影响公司或行业前景、可能带来价格变化的消息。 | 区分已公布的驱动因素和持有期尚待公布的事件。 | 第6、11章，页44–50、98–102 |
| 跳空（gap up / gap down） | 次日开盘价相对前一日收盘价发生离散变化。 | 隔夜持仓策略须在前一天收盘前决策；盘后观察清单只能记录情景。 | 第7、12章，页63–66、112–114 |
| 热门板块狂热（hot sector mania） | 公共故事吸引资金进入一组有关联的公司，参与可能扩散并最终衰退。 | 区分主题共振、个股消息和行情后段的拥挤。 | 第6、12章，页48–49、114–120 |
| 计划收益风险比（risk to reward ratio） | 作者示例用可望获得的价差除以可能损失的价差；2 表示潜在收益为计划风险的两倍。 | 写出分子和分母，避免因英文词序倒算。计划倍数与胜率、已实现收益各自独立。 | 第5、13章，页36–37、121 |
| 头寸规模（position sizing） | 股数取决于账户风险预算和入场到止损的每股风险。 | 区分拟投入的本金和按止损估计的亏损；跳空会令两种亏损口径产生差异。 | 第5章，页39–40 |
| 提醒 / 限价 / 止损（alert / limit / stop） | 提醒只发通知；限价约束可接受报价；止损用某个价格触发风险退出。 | 触发、报单与成交分别记载。越过止损或限价未成交均影响复盘。 | 第2、13章，页121–125；术语表 |
| 分批退出 / 跟踪止损（scaling out / trailing stop） | 逐次退出部分持仓，余仓可在趋势有利时调整止损参考价。 | 按各批数量加权计算实际收益，另列未实现部分。 | 第13章，页122–125 |
