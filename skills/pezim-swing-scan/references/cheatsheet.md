# 决策规则速查 — How to Swing Trade

| 能力 | 一句话规则 |
|---|---|
| 市场宽度与板块轮动 | 解释市场参与度及行业周月强弱，判断方向是否一致 |
| 常规收盘筛选 | 从股票池筛出趋势延续或反转候选并记录过滤条件 |
| 隔夜动量观察 | 检查消息首日、尾盘延续与不利跳空情景 |
| 热门板块追踪 | 区分题材的早期证据、跟风股与过热迹象 |
| 图表与失效位 | 为形态标出触发、失效与最近目标 |
| 持仓窗口的事件核查 | 辨别已公布消息与待公布二元事件、流动性及财务风险 |
| 交易空间与股数 | 复算做多做空的收益风险、风险预算和拟议仓位 |
| 次日跟踪与日志 | 收盘生成次日计划，复核入场漂移、分批退出和执行偏差 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
